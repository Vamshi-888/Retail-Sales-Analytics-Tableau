# Retail Sales Analytics Dashboard (Tableau)

## 📌 Project Overview
This project analyzes retail sales performance using Tableau. It helps understand sales trends, category performance, and regional contribution through interactive data visualizations.

## 📊 Dashboard Features
- Monthly Sales Trend
- Sales by Category
- Sales by Region Map
- Interactive filters

## 🛠 Tools Used
- Tableau
- Excel / CSV Dataset

## 🔗 Live Dashboard

## ✅ Key Insights
- Identified top revenue-generating categories
- Observed sales performance trend over time
- Compared region-wise sales distribution
